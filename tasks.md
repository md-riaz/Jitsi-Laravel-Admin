- [ ] Meetings cannot be joined outside allowed join window (server-side enforced).
- [ ] Dashboard pages exist via Tyro Dashboard Artisan scaffolding only.
- [ ] Authorization is enforced through Tyro roles/privileges.
- [ ] Jitsi is used as external media plane only (no scheduling state stored/derived from Jitsi).

- [ ] Notifications + ICS delivery and audit logging are functional for phase scope.
